# Hotel Photo Bot — production MVP

## Что реализовано
- 4 роли: OWNER, ADMIN, MANAGER, PHOTOGRAPHER.
- Мульти-роли: один Telegram-пользователь может иметь несколько ролей, меню объединяется.
- Бронирование: отель, номер, клиент, дата/время, пакет, менеджер, фотограф.
- Съёмка: назначена → принята → прибыл → начата → готова менеджеру.
- Отдельный модуль продаж: оформить может фотограф/менеджер/админ/владелец; отдельно фиксируются `created_by` и `credited_user`.
- Комиссия считается по сотруднику, которому засчитана продажа; процент настраивается по роли.
- Зарплатные записи: salary/percent/bonus/premium/penalty/adjustment/payout через модель payroll.
- Отели, пакеты, сотрудники, настройки, аудит, планы, смены, уведомления, CRM — модели БД подготовлены.
- PostgreSQL с постоянным volume в Docker Compose.

## Запуск
1. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN`.
2. `docker compose up -d --build`.
3. Первый пользователь с Telegram ID из `ADMIN_TELEGRAM_IDS` получает OWNER.

Для локального запуска нужен PostgreSQL и `python -m app.main`.
