Изменения используют существующие функции и таблицы. Рабочие данные, назначения,

ролями; при двух ролях сохраняется доступ по обеим. Личная сводка владельца и
администратора остаётся личной, общий список съёмок им по-прежнему доступен.

## Не проверено и внешняя настройка

- Android/iPhone и реальный Telegram WebView; production, живые токены и данные.
- PostgreSQL-блокировки при конкурентных транзакциях, применение миграций на старой
  рабочей базе, Docker и восстановление резервной копии. SQLite этого не доказывает.
- Реальные OpenAI/OCR, Яндекс.Диск, Telegram media API и TURN. Для их отдельной
  приёмки нужны действующие настройки сервиса и согласованный бюджет платных API.
- Все экраны и роли вручную, нагрузка и звонки в мобильных сетях.
- Ранее загруженные локальные снимки остаются офлайн-данными: отключённое устройство
  не может узнать о снятии роли до связи с сервером. Этот PR ограничивает новые
  серверные чтения и записи, а не обещает удалённое стирание уже сохранённых копий.
