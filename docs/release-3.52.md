# Photo Boss 3.52 — главная, уведомления и сохранение работы

Главная больше не показывает блок «Записи и помощь менеджерам», таблицу отелей без записей и его настройки. Обычная запись гостей, данные отелей, менеджеров и действующие каналы напоминаний сохранены.

Центр уведомлений показывает короткие карточки, время и связанное действие. Прочитанные сообщения отличаются от новых; счётчик отражает всё доступное непрочитанное, включая старые страницы. Можно прочитать отдельное событие или всё до текущего номера события, затем открыть предыдущую страницу. Новые сообщения, пришедшие во время чтения всех, не теряются. Список, счётчик и отметки используют одинаковые серверные права; старые события не удаляются. Один event key не создаёт дубликаты даже при двух одновременных транзакциях.

Временная ошибка загрузки страницы сохраняет привязку очереди к текущему сотруднику. Повтор страницы восстанавливает доступ к очереди без нового входа; ошибки доступа по-прежнему блокируют отправку. Выбранные файлы и ключи повторов сохраняются.

Подготовлены отдельные SMS-напоминания гостям: подтверждение актуальной записи, явное согласие, телефон, интервал, перенос/отмена и устойчивое состояние отправки. Сервис отправки не подключён, поэтому функция отключена. Ни наличие телефона, ни приём сообщения провайдером не означают доставку. Неопределённый результат требует сверки, а не повторной отправки. Реальные SMS гостям не отправлялись. Подключение описано в `guest-sms.md`.

Продажа и связь фотографий с клиентской галереей из 3.51 сохранены. Ключ Яндекс.Диска, тариф Render и платёжные правила не менялись.

Проверки: изолированные API/SQLite/PostgreSQL тесты, гонка одного события, большая история, реальные браузерные маршруты с синтетическими данными, мобильный экран, очередь после временной ошибки и ограничения доступа. Публикация подтверждается отдельно по номеру сборки и рабочим статическим файлам.
