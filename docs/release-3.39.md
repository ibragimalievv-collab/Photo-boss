# 3.39 — открытие Яндекс.Диска из продажи одним нажатием

При выборе «Выбрать на Яндекс.Диске» приложение сразу открывает папку,
привязанную к съёмке. Если папка ещё не привязана, владелец сразу видит
список папок рабочего Диска. Просмотр папок ничего не привязывает и не
меняет продажу; привязка происходит отдельной явной кнопкой.

«Прикрепить ссылку» открывает поле ссылки. Оно не запускает просмотр
закрытого рабочего Диска. Сотрудникам доступна только привязанная папка
их продажи; серверные ограничения доступа сохранены.

При ошибке открытия показаны причина и кнопка повтора. Повторяется
последний запрос папки, а уже отмеченные фотографии сохраняются.
Запоздавший ответ после переключения на устройство не открывает Диск
снова и не подменяет текущий выбор. При успешной смене привязанной папки
старые отметки сбрасываются по новой серверной версии привязки.

Браузерная регрессия `tests/disk_sale_browser_check.py` проверяет пустую
привязку, автоматическое открытие списка, отдельное поле ссылки, явную
привязку папки, потерю ответа списка, сохранение отмеченных кадров,
запоздавший ответ после смены источника, продолжение черновика владельцем
и повтор отправки без второй продажи или начисления. Проверка использует
изолированную базу и имитацию Диска; она добавлена в CI.

Исходные фотографии не копируются и не удаляются. Пользовательские данные
браузера и очередь загрузки очищать для обновления не требуется.
