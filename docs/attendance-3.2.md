# Mini App 3.2 — начало и завершение смены

Исправлена невидимая кнопка: отдельный блок смены расположен над рабочей сводкой, независимо от доступа к созданию записей. Фотограф и менеджер записи могут отметиться; владелец/администратор без рабочей роли получают вход в контроль графика, а не чужую личную отметку.

## Сценарий

Геолокация запрашивается только после нажатия. Поддерживается Telegram LocationManager с резервным browser Geolocation API на устройствах без этой возможности. Отказ пользователя не обходится другим способом запроса. После координат нужно фото в полный рост для начала или фото рабочего места для ухода, затем явное подтверждение. Закрытие окна не подтверждает смену.

Используются существующие shift_check_ins / shift_check_outs и payroll_entries. Время устанавливается сервером. Запрос без авторизации, чужой идентификатор, роль без доступа, неверные координаты/дата/файл отклоняются. Геолокацию старше пяти минут нужно получить заново. Повтор подтверждённой операции не создаёт второй штраф. Для сохранения фото бот должен успешно принять изображение и вернуть file_id.

Правило 09:00 / 500 рублей сохранено из действующего бота. Тестовый бесплатный хостинг не означает учебную базу: подтверждение смены создаёт реальную запись. Автоматических тестовых отметок в рабочей базе не делалось.

## Выполненные локальные проверки

- 32 Python-проверки сценариев на временной SQLite: права, два рабочих типа ролей, последовательность, истечение координат, отказ Telegram, повторное подтверждение, штраф.
- 13 JavaScript-проверок: состояния, native/browser API, отказ, некорректные координаты, тайм-аут.
- 16 Chromium-проверок компонента с подменёнными API/GPS: карточка, три ширины, три темы, фото и шаги подтверждения; 0 ошибок страницы.

Это НЕ сквозной тест рабочего Telegram-аккаунта. Browser network недоступна в тестовой среде, поэтому UI проверялся локально через set_content с явными подменами. Блокировки строк PostgreSQL и физическая камера/разрешения Android/iOS требуют проверки на устройстве. Дополнительные небольшие регрессионные тесты включены в tests/test_attendance_validation.py.

## Честные ограничения

- Координаты сохраняются, но проверка расстояния до отеля не настроена: нужны эталонные координаты отелей и согласованный радиус. Присутствие в отеле не объявляется подтверждённым.
- Фото не доказывает время съёмки; отдельная проверка живого присутствия не реализована.
- Сохранена исходная модель одной отметки начала/конца в локальную дату; ночные переходящие и несколько раздельных смен не добавлены этим изменением.
- Изображение хранится через Telegram в личном чате сотрудника, защищено от стандартной пересылки; абсолютного запрета скриншотов нет.
- Платные серверы и услуги не включались.

## Проверка после публикации

Закрыть Mini App полностью и открыть кнопкой Photo Boss в рабочем боте. У сотрудника проверить блок «Смена и геолокация». Сначала проверить отказ доступа к GPS: отметка не должна появиться. Затем выполнить реальную отметку только сотрудником, действительно выходящим на смену. На время тестирования не подтверждать фиктивные выходы: после 09:00 действует существующее начисление 500 рублей. У владельца без роли фотографа/менеджера проверить кнопку контроля графика.
