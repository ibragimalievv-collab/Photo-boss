# Фотобосс: ответы на отклики Авито, версия vacancy-profile-v6

Исправление заменяет общий ответ «уточню у владельца» последовательным разговором:
подтверждённые условия вакансии → вопросы кандидата → имя, город, опыт, выход и
согласие с условиями → карточка для владельца. Окончательное решение о найме и
подтверждение встречи остаются за человеком. Внешние AI API не используются.

## Что входит

- Условия хранятся отдельно по коду вакансии. Владелец и администратор редактируют
  их в `/app/hr-avito.html`; обновление защищено номером редакции и аудитом.
- Готовые условия двух ранее утверждённых вакансий подставляются только при
  совпадении кода и SHA256 исходного опубликованного payload. Новые редакции
  владельца никогда не перезаписываются. Для других вакансий нужно заполнение.
- Можно привязать действующее объявление: сервер проверяет его наличие среди
  активных вакансий подключённого аккаунта. Публикация платных объявлений и
  поиск резюме этим кабинетом не запускаются.
- Предпросмотр ответа работает без отправки сообщений кандидатам.
- Карточка содержит явно сообщённые сведения и последние 200 сообщений чата.
  Кабинет показывает последние 200 карточек. Неизвестные сведения отмечаются
  как «Не выяснено». Решения по возрасту, гражданству и другим чувствительным
  признакам автоматически не принимаются.
- Новые запросы на проверку, готовые анкеты и ручной перехват создают запись
  в личном кабинете уведомлений владельца. Текст уведомления не содержит анкету.
- Сообщение человека или запрос кандидата связать с менеджером приостанавливает
  ассистента в конкретном чате. Возврат ассистенту — отдельное действие менеджера.
- Отказ кандидата прекращает автоматические ответы; кабинет не позволяет
  принудительно возобновить их.
- Outbox резервируется до отправки, inbox запоминает все сообщения обработанной
  группы, включая сообщения с одинаковым временем в секундах. Неопределённый
  результат отправки не повторяется автоматически и блокирует этот чат.
  Остальные чаты продолжают обрабатываться. Неопределённые отправки необходимо
  сверять в Авито вручную; автоматического снятия этой блокировки нет.

## Подключение в действующем окружении

1. Подтвердить репозиторий, ветку, домен и базу нового Фотобосс на Timeweb.
   Само наличие этого PR не подтверждает его публикацию в новом окружении.
2. Создать резервную копию целевой базы. При запуске добавляются таблицы
   `hr_avito_terms`, `hr_avito_sessions`, `hr_avito_inbox`; прежние данные
   вакансий и outbox сохраняются.
3. Развернуть согласованный commit в подтверждённом окружении. Существующие
   `AVITO_CLIENT_ID` и `AVITO_CLIENT_SECRET` остаются только в серверных настройках.
   Секреты не помещаются в исходники, кабинет или журналы.
4. Проверить `/health/avito`: enabled/ready, paused/reason, managedVacancies,
   lastCheck и dialogueVersion. Наличие ключей не доказывает успешный доступ к API.
5. Войти в Фотобосс владельцем/администратором и открыть `/app/hr-avito.html`.
   Если вакансии ещё не связаны, подключить их по номеру действующего объявления.
   Проверить и подтвердить условия каждой вакансии.
6. Прогнать вопросы об оплате, графике, жилье, обучении и выходе через предпросмотр.
7. На согласованном тестовом диалоге проверить полный разговор, карточку владельца,
   отказ, ручной перехват, возврат ассистенту и отсутствие повторных отправок.

## Проверки

`python -m pytest -q tests/test_avito_dialogue.py tests/test_avito_worker.py tests/test_avito_transport_diagnostics.py`

Проверки используют синтетические сообщения, подменённый API и отдельную SQLite
в памяти. Они не отправляют сообщения, не публикуют объявления и не проверяют
production-ключи, права Авито, PostgreSQL или фактическую публикацию на Timeweb.
